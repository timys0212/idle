# 고양이의 느긋한 낚시

Pygame으로 제작 중인 픽셀풍 힐링 IDLE 낚시 게임입니다.

## 실행

```bash
pip install pygame
python main.py
```

## 조작

- `1`~`6`: 낚시, 도감, 배낭, 어항, 상점, 제작소 이동
- `Space`: 낚시 시작, 후킹, 물고기 끌어올리기
- `C`: 진행 중인 낚시 취소
- `↑`/`↓`: 목록 선택
- `Enter`: 선택한 항목 사용
- `Shift+Enter`: 배낭의 물고기 손질
- `U`: 어항 확장
- `Esc`: 종료

종료할 때 자동 저장되며, 다시 실행하면 어항의 오프라인 수익을 계산합니다.
